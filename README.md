# UTS Praktikum Pemrograman Web - Tipe B (Sistem Inventaris Laboratorium)

CRUD inventaris laboratorium dengan Laravel, PDO (prepared statement), dan MySQL. Halaman utama UTS ada di route /inventaris.

## Cara menjalankan
1. composer install
2. Salin .env.example menjadi .env, lalu sesuaikan DB_PASSWORD
3. Jalankan database/sql/inventaris_lab_2401020018.sql di MySQL
4. php artisan key:generate
5. php artisan serve, lalu buka /inventaris
